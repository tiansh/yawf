## 使用说明

新版支持微博主页和搜索页的关键词、广告、推广热搜及界面清理。
在微博顶部账号菜单或脚本管理器菜单中打开「药方设置」，开关即时生效。

* 关键词按微博账号保存，支持每行一个关键词的 UTF-8 TXT 追加导入和导出。
* 用户过滤读取微博原生黑名单，仅过滤「微博、互动、关注」三个屏蔽范围全部勾选的用户。
  进入页面和返回标签页时同步黑名单，停留期间每 5 分钟更新，也可手动刷新。
* 支持默认进入最新微博、折叠收藏标签，以及右栏全部隐藏后加宽中间栏。
* 搜索页共用当前账号设置；图片搜索只匹配页面提供的摘要，未提供数字 UID 的作者不按昵称过滤。

已有 `CONFIG` 中的关键词和同名清理开关继续使用。
旧的自定义用户过滤列表仍保留在存储中，但不再参与过滤；需要在微博原生黑名单中管理用户屏蔽。
默认开启「默认进入最新微博」，可在浏览设置中关闭。

## 本地检查

使用 Node.js 18 或更新版本，无需安装额外依赖：

```sh
node --check yyawf.user.js
node --test test/yyawf.test.cjs
```

测试覆盖配置迁移、关键词导入导出、黑名单响应校验、过滤决策、首页跳转及收藏标签布局。
